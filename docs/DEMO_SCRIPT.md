# 4–5 minute recording script

Record your screen with the Telegram chat visible. Speak briefly over each
section — reviewers are grading whether *you* understand what the system does,
not your presentation skills. Don't rush; the whole run is ~30 messages.

**Before you start:** demo against the **deployed** bot — that is the one the
reviewers will drive. Confirm it answers, then open Telegram full-screen and
send `/new` so the recording starts on an empty conversation.

---

### 0:00 — Frame it (15s, no typing)

> "This is a kirana store agent. The owner runs the whole shop from Telegram —
> no app, no forms. Every business rule is enforced in the database and the
> tool layer, not in the prompt. Let me show you."

---

### 0:15 — Receive stock

```
50 packets of Maggi came in, cost ₹12, MRP ₹14
```

> "The model searched the catalog, found the SKU, and called receive_stock.
> Notice I didn't give it a product id — grounding comes from a tool."

```
new item: Amul Butter 100g, GST 12%, MRP ₹62
```

---

### 0:45 — Multi-turn bill with an edit

```
make a bill: 2kg sugar, 1 aashirvaad atta 5kg, 4 maggi, 1 amul butter, UPI
```

> "One message, seven tool calls — search each item, open a draft, add four
> lines, set payment. The bill is a draft; no stock has moved yet."

```
drop the butter, make it 6 maggi
```

> "Editing mid-build. 'Drop the butter' is a quantity-zero call, not a delete
> branch I wrote."

```
done
```

> "*Now* stock moves — atomically, in one transaction, with the GST computed
> per slab."

---

### 1:45 — Oversell guard (the money shot)

```
how much surf excel is left?
```

*(note the number — say it's 4)*

```
bill 10 surf excel
```

> "Refused. And it's refused at the tool layer, not by the prompt — there's a
> CHECK constraint on the column and a guarded decrement in the finalize
> transaction. Even raw SQL can't push stock negative. There's a test that
> tries."

---

### 2:15 — Khata cycle

```
put ₹500 on Ramesh's credit
Ramesh paid ₹300
what's Ramesh's balance?
```

> "₹200. Now watch a guardrail:"

```
Suresh paid ₹100
```

*(Suresh has no khata → refused)*

> "You can't settle a khata that doesn't exist. Again, service layer."

---

### 2:50 — Ambiguity → clarifying question

```
add 2kg atta to a new bill
```

> "Two attas exist — Aashirvaad 5kg and loose. It asked which one. That
> question came from the model reasoning over the search result, not from a
> branch in my code."

*(answer it, then close the bill)*

---

### 3:15 — Real artifacts

```
send me that bill as a PDF
```

*(open the PDF on screen — point at the HSN column, the CGST/SGST split, the
slab summary, the round-off line)*

> "A proper GST tax invoice. Per-item HSN, CGST and SGST split, slab-wise
> summary, round-off, amount in words — generated by the agent's own tool."

```
make this week's sales analysis deck
```

*(open the PPTX — flip through the slides)*

> "Eight slides with real matplotlib charts — daily revenue, top items,
> payment mix, GST by slab, and reorder suggestions from sales velocity."

---

### 4:00 — Memory across sessions (finish strong)

```
always assume UPI unless I say cash
```

```
/new
```

> "That cleared the conversation — new session, empty context window."

```
bill 4 maggi
```

> "It assumed UPI. That preference isn't in the conversation any more; it's in
> SQLite, and it gets injected when a session starts. Memory lives outside the
> context window — which was the actual requirement."

---

### 4:30 — Close (15s)

> "104 tests cover the GST maths, the oversell guard, idempotent retries and
> threaded concurrency — all of them pass with the LLM removed, because the
> rules aren't in the prompt. Thanks."

---

## Recording tips

- **Windows:** Xbox Game Bar (`Win+G`) or OBS. **Mac:** `Cmd+Shift+5`.
- Type the messages fresh — don't paste. Reviewers can tell, and a live typo
  that the agent handles gracefully is a bonus, not a problem.
- If a response is slow, let it sit. Editing out a 4-second pause looks worse
  than the pause.
- Keep the whole thing under 5 minutes. If you're over, cut section 2:50
  (ambiguity) — it's the least load-bearing.
- Upload to YouTube unlisted or Google Drive, and put the link in the README.
